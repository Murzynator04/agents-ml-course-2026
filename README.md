# Laboratoria z pracy z agentami AI

Repozytorium zawiera prace semestralne z kursu „Praca z agentami AI”. Każde laboratorium ma osobny katalog ze sprawozdaniem i materiałami do weryfikacji wyników. Kolejne laboratoria będą zapisywane w katalogach `lab2/`, `lab3/` i następnych.
